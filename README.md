## 🚀 خطوات تثبيت وتشغيل المشروع

### 1. إعداد وتشغيل الـ Backend

1. افتح موجه الأوامر (Terminal) وانتقل إلى مجلد الـ backend:
   ```bash
   cd backend
   ```

2. قم بتثبيت الحزم والمكتبات اللازمة (عند إضافة `package.json`):
   ```bash
   npm install
   ```

3. قم بإنشاء ملف `.env` في مجلد `backend` وضع المتغيرات البيئية اللازمة:
   ```env
   PORT=5000
   NODE_ENV=development
   DATABASE_URL=your_database_connection_string
   JWT_SECRET=your_jwt_secret_key
   ```

4. تشغيل خادم التطوير:
   ```bash
   npm run dev
   # أو
   node src/server.js
   ```
   سيعمل السيرفر افتراضياً على: `http://localhost:5000`

---

### 2. إعداد وتشغيل الـ Frontend

1. افتح نافذة Terminal ثانية وانتقل إلى مجلد الـ frontend:
   ```bash
   cd frontend
   ```

2. قم بتثبيت الحزم والتبعيات:
   ```bash
   npm install
   ```

3. تشغيل واجهة التطوير (Vite Dev Server):
   ```bash
   npm run dev
   ```

4. افتح المتصفح على الرابط الظاهر في التيرمينال (عادةً `http://localhost:5173`).

## 📂 هيكل المشروع العام

```text
Echo Egypt/
├── backend/                  # خادم الباك إند (Node.js / Express)
│   └── src/
│       ├── config/           # إعدادات قاعدة البيانات والتطبيقات الخارجية
│       ├── controllers/      # معالجات الطلبات والردود
│       ├── middleware/       # برمجيات وسيطة للأمان والتحقق والتحكم في الأخطاء
│       ├── models/           # نماذج البيانات
│       ├── routes/           # مسارات الـ API
│       ├── services/         # منطق العمليات (Business Logic)
│       ├── validators/       # التحقق من صحة المدخلات
│       ├── app.js            # إعداد تطبيق Express
│       └── server.js         # تشغيل الخادم
│
└── frontend/                 # واجهة المستخدم (React + Vite)
    ├── public/               # الملفات الثابتة (أيقونات، صور)
    └── src/
        ├── assets/           # الوسائط والصور الداخلية
        ├── components/       # المكونات القابلة لإعادة الاستخدام
        │   └── admin/        # [جديد] مكونات لوحة تحكم الإدارة
        ├── context/          # إدارة الحالة العامة (State Management)
        ├── layouts/          # هياكل وتخطيطات الصفحات (Layouts)
        ├── pages/            # صفحات الموقع
        │   └── admin/        # [جديد] صفحات لوحة تحكم الإدارة
        ├── services/         # خدمات الاتصال بالـ Backend API
        ├── App.jsx           # المكون الجذري وموجه المسارات
        ├── index.css         # التنسيقات العامة
        └── main.jsx          # نقطة انطلاق التطبيق
```

## 🛠 شرح هيكل الـ Backend

- **`config/`**:
  - `database.js`: إدارة الاتصال بقاعدة البيانات.
- **`controllers/`**:
  - استقبال بيانات طلبات الـ HTTP والتواصل مع الـ Services وإرجاع الاستجابات المناسبة (`auth`, `experience`, `memory`, `trip`, `user`).
- **`middleware/`**:
  - `auth.middleware.js`: التأكد من صلاحية رمز المصادقة (JWT Token).
  - `authorize.middleware.js`: التأكد من رتبة المستخدم (مثل Admin أو User عادي).
  - `error.middleware.js`: الإمساك بالأخطاء ومعالجتها وتوحيد شكل الاستجابة.
  - `validate.middleware.js`: فحص البيانات قبل تمريرها للـ Controller.
- **`models/`**:
  - الجداول أو الـ Schemas الخاصة بقاعدة البيانات (`User`, `Experience`, `Memory`, `Trip`).
- **`routes/`**:
  - ربط روابط الـ Endpoints بالـ Controllers المناسبة وتطبيق الـ Middlewares.
- **`services/`**:
  - عزل منطق الأعمال الحسابي والتعامل مع قواعد البيانات عن طبقة الـ HTTP.
- **`validators/`**:
  - مخططات التحقق من صحة المدخلات (Validation Schemas).

## 🎨 شرح هيكل الـ Frontend بالتفصيل

### مكونات لوحة الإدارة (`components/admin/`)

| الملف | الوظيفة والدور |
| :--- | :--- |
| **`AdminSidebar.jsx`** | القائمة الجانبية للتنقل بين أقسام لوحة الإدارة (لوحة البيانات، التجارب، المستخدمين، الرحلات، البلاغات، إلخ). |
| **`AdminHeader.jsx`** | الشريط العلوي للوحة الإدارة؛ يحتوي على اسم المستخدم المسؤول، التنبيهات، زر تسجيل الخروج، وتبديل الوضع (Dark/Light). |
| **`AdminStats.jsx`** | بطاقات عرض الإحصائيات السريعة (عدد المستخدمين، إجمالي الحجوزات، الإيرادات، التجارب النشطة). |
| **`AdminTable.jsx`** | جدول بيانات عام مرن وقابل لإعادة الاستخدام لعرض القوائم (المستخدمين، الرحلات، التجارب) مع الترقيم والفرز. |
| **`AdminSearch.jsx`** | حقل بحث وفلترة مخصص للجداول واللوحات للبحث السريع وتصفية البيانات بحسب الحالة أو التاريخ. |
| **`AdminModal.jsx`** | نافذة منبثقة (Modal/Dialog) تستخدم لتأكيد الحذف، عرض التفاصيل، أو إدخال/تعديل البيانات السريعة. |
| **`StatusBadge.jsx`** | شارة ملونة لعرض حالة العنصر (مثل: نشط `Active`، قيد المراجعة `Pending`، معطل `Disabled`، ملغي `Cancelled`). |

---

### تخطيط لوحة الإدارة (`layouts/`)

| الملف | الوظيفة والدور |
| :--- | :--- |
| **`AdminLayout.jsx`** | الهيكل الحاضن لجميع صفحات لوحة الإدارة؛ يجمع `AdminSidebar` و `AdminHeader` مع منطقة عرض المحتوى الداخلي (`<Outlet />`). |
| **`MainLayout.jsx`** | الهيكل الحاضن لصفحات الموقع العامة للمستخدمين (يحتوي على الـ Navbar والـ Footer). |
| **`AuthLayout.jsx`** | تخطيط مخصص لصفحات تسجيل الدخول وإنشاء الحساب. |

---

### صفحات لوحة الإدارة (`pages/admin/`)

| الملف | الوظيفة والدور |
| :--- | :--- |
| **`Dashboard.jsx`** | الصفحة الرئيسية للوحة الإدارة؛ تحتوي على ملخص الأرقام، المخططات البيانية، وآخر النشاطات. |
| **`Experiences.jsx`** | صفحة إدارة واستعراض جميع التجارب والأماكن السياحية المسجلة مع إمكانية الفلترة والبحث. |
| **`CreateExperience.jsx`** | نموذج (Form) لإضافة تجربة أو معلم سياحي جديد وتحديد الصور والأسعار والتفاصيل. |
| **`EditExperience.jsx`** | تعديل بيانات تجربة حالية وتحديث وسائطها وتفاصيلها. |
| **`Memories.jsx`** | مراجعة وإدارة ذكريات وصور المستخدمين والموافقة عليها أو حذف غير الملائم منها. |
| **`Users.jsx`** | إدارة حسابات المستخدمين، صلاحياتهم، حظر أو تفعيل الحسابات، وتغيير الأدوار. |
| **`Trips.jsx`** | متابعة حجوزات الرحلات وجداولها وحالات الدفع والتأكيد. |
| **`Categories.jsx`** | إدارة التصنيفات السياحية (أثرية، شاطئية، بيئية، ثقافية، إلخ) وإضافة تصنيفات جديدة. |
| **`Reports.jsx`** | متابعة بلاغات المستخدمين، ومراجعة الشكاوى والتقارير التحليلية للنظام. |

---

### خدمات الإدارة (`services/`)

| الملف | الوظيفة والدور |
| :--- | :--- |
| **`admin.service.js`** | يحتوي على جميع دوال الاتصال الخاصة بالإدارة (جلب الإحصائيات، إدارة المستخدمين، اعتماد التجارب، حذف العناصر، جلب التقارير). |
| **`api.js`** | إعداد مثيل Axios الأساسي والـ Interceptors لإرفاق توكن الدخول والتعامل مع الأخطاء العامة. |

### مكونات وصفحات المستخدم العامة

- **`components/`**:
  - `Navbar.jsx`: شريط التصفح العلوي لزوار الموقع.
  - `Footer.jsx`: التذييل السفلي للصفحات.
  - `Button.jsx`: زر مخصص موحد التصميم.
  - `ExperienceCard.jsx`: بطاقة عرض ملخص التجربة السياحية.
  - `MemoryCard.jsx`: بطاقة عرض ذكرى أو منشور شاركه زائر.
  - `MoodSelector.jsx`: أداة لاختيار الحالة المزاجية لاقتراح رحلات وتجارب تناسب الزائر.
  - `Loading.jsx`: مؤشر تحميل أنيق.
- **`pages/`**:
  - `Explore.jsx`: استكشاف جميع الأماكن والتجارب السياحية في مصر.
  - `ExperienceDetails.jsx`: الصفحة التفصيلية لتجربة معينة.
  - `Memories.jsx`: جدار الذكريات المجتمعي.
  - `Trips.jsx`: تنظيم وتخطيط الرحلات.
  - `Saved.jsx`: المفضلة والتجارب المحفوظة.
  - `Profile.jsx`: الملف الشخصي للمستخدم.
  - `Login.jsx` & `Register.jsx`: صفحات تسجيل الدخول وإنشاء حساب.
- **`context/`**:
  - `AuthContext.jsx`: توفير حالة تسجيل الدخول وبيانات المستخدم الحالي لكامل أجزاء التطبيق.
